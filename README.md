# Grokking Algorithms — C++

Репозиторий с реализациями алгоритмов из книги **«Грокаем алгоритмы»** (Адитья Бхаргава) на C++.

## О репозитории

Я читаю книгу и по ходу реализую каждый алгоритм на C++. Параллельно веду конспекты в **Obsidian** — там разборы, схемы, псевдокод и заметки о сложности. Цель не просто «написать код», а понять, как и почему алгоритм работает.

## Что внутри

- **Реализации на C++** — с комментариями и, где возможно, тестами.
- **Примеры использования** — небольшие `main`-функции для проверки.
